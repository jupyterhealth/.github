# Welcome to the JupyterHealth community 👋

JupyterHealth is a project that connects wearable, clinical, and patient-generated data to computational and AI tools for health care.
All of the tools it builds are open source, built on [Jupyter](https://jupyter.org) and open standards like [FHIR](https://hl7.org/fhir) and [Open mHealth](https://www.openmhealth.org), and made for researchers, clinicians, and patients.

- See the [JupyterHealth documentation](https://docs.jupyterhealth.org) to learn more.
- Chat in the [#jupyterhealth channel on the Jupyter Zulip](https://jupyter.zulipchat.com/#narrow/channel/531270-jupyterhealth).
- Use [GitHub Discussions](https://github.com/orgs/jupyterhealth/discussions) to ask questions, share your experience, or report problems you run into.
- See [jupyterhealth.org](https://jupyterhealth.org/#contact) to talk to the team about a deployment or integration.
- You can ask for access to [try JupyterHealth with the Berkeley demo](https://docs.jupyterhealth.org/#try-the-berkeley-demo) Exchange and Hub.

## Contributing

JupyterHealth is an open project, and we welcome contributions from anyone.
See the [community guide](https://docs.jupyterhealth.org/community) to get involved.
JupyterHealth follows the [Jupyter Code of Conduct](https://jupyter.org/governance/conduct/code_of_conduct.html).
